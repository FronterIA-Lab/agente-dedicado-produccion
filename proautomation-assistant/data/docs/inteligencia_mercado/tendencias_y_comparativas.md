# Inteligencia de Mercado — Automatización y Soldadura Industrial

## Tendencias Industria 4.0 relevantes para el gerente
- **Trazabilidad de soldadura:** registro de parámetros por pieza (corriente, voltaje, wire feed) para auditorías OEM.
- **Digital twin / simulación offline:** reduce tiempo de programación en piso y anticipa colisiones.
- **Mantenimiento predictivo:** sensores de consumo de tips, ciclos de pinza y vibración en posicionadores.
- **Celdas flexibles:** tool changers y fixtures modulares ante mix alto de SKUs.
- **Seguridad integrada:** escáneres y control seguro de velocidad como estándar de RFQs TIER1.

## Escasez de mano de obra calificada en soldadura
- Déficit estructural de soldadores calificados en Norteamérica y México industrial.
- Alta rotación eleva costo de calidad (retrabajo, no conformidades, entrenamiento).
- Automatización robótica convierte el know-how en proceso repetible y documentable (WPS + PLC).
- Argumento comercial: "La celda no reemplaza al experto; multiplica su capacidad y estabiliza la calidad 24/7."

## Comparativa teórica MIG vs Láser
| Criterio | MIG / GMAW | Láser |
|---|---|---|
| Inversión inicial | Menor | Mayor |
| Velocidad en espesores medios | Alta | Muy alta en delgados |
| Distorsión térmica | Media | Baja |
| Tolerancia a gaps / ajuste de junta | Mejor | Más exigente |
| Consumibles | Alambre + gas | Menos consumible, más ópticas |
| Galvanizado | Viable con pulso + extracción | Posible, requiere control de zinc/humos |
| Caso típico | Brackets, estructuras, volumen medio-alto | Uniones estéticas, AHSS, precisión |

**Recomendación práctica ProAutomation:** partir de MIG pulsado robotizado para la mayoría de RFQs automotrices de chapa; evaluar láser solo cuando el cliente exige distorsión mínima, estética crítica o especificación OEM explícita.

## Drivers de decisión del cliente (qué preguntar / qué argumentar)
1. Volumen diario y mix de partes
2. Costo de calidad actual (PPM, retrabajo)
3. Disponibilidad de soldadores / turnos
4. Plazo de arranque de producción (SOP)
5. Requisitos OEM de trazabilidad y seguridad
6. Espacio en planta y utilities disponibles
